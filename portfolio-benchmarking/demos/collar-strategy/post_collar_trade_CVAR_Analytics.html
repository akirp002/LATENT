Overview — Tracking Error vs. Active CVaR
Three different TE numbers, deliberately: Tracking Error (dashboard) is each path's OWN native benchmark — the FF5 max-Sharpe benchmark for Current/C/D, but a completely different 13-sleeve Excel policy benchmark for SAA/SAA 3% (optimize_saa_mvo.py's te_total()) — so these numbers are NOT comparable across paths. SAA-benchmark TE fixes that: it re-scores every path's SAME already-optimized post-trade weights (no re-optimization, no path's trade changes) against the one SAA sleeve/policy benchmark, so this column IS directly comparable path to path (see saa_benchmark_te.py). Scenario TE is a third, separate thing again — the empirical std dev of the same 58 scenario active returns Active CVaR is built from, which is the only one of the three that responds to the MSTR collar (compare its "no collar" vs. "100% collar" columns).
