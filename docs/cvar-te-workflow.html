CVaR / tracking-error computation workflow

Real track: monthly returns and the benchmark wealth curve feed analytics.risk.scenario_matrix, which builds the overlapping 12-month scenario matrix that analytics.risk.active_cvar turns into Active CVaR. Betas and residual variance feed optimize_tax_cvar_mvo.py's own te_of quadratic form (factor covariance + idiosyncratic term — not yet routed through analytics.risk.tracking_error). Both feed the SLSQP solve, whose trade proposals feed portfolio_risk_attribution.py's per-factor Euler decomposition and generate_rebalance_dashboard.py.

Demo boundary: the MSTR collar what-if (demos/collar-strategy/) and the SAA-benchmark TE re-scorer read the real optimizer's saved trade proposals and scenario matrix but never re-optimize or write back into them. The rolling-beta/Ledoit-Wolf prototype (benchmark_tracking_error_model.py) is a fully separate, synthetic-portfolio TE model feeding only the docs showcase.
