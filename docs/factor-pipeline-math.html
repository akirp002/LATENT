01

Category PCA

quant_model_macro_1.py

Each economic category's raw series are standardized, then collapsed to a single factor via the first principal component.

Standardize each series c \[ z_{t,c} = \frac{x_{t,c} - \bar{x}_c}{s_c} \]
Sample covariance of the standardized block, eigendecomposition \[ \Sigma = \frac{1}{T-1} Z^\top Z \; = \; V \Lambda V^\top, \qquad \Sigma v_k = \lambda_k v_k \]
Factor score and explained variance \[ f_t = Z_t v_1, \qquad \text{EVR}_1 = \frac{\lambda_1}{\sum_k \lambda_k} \]

Run separately per category (Growth, Inflation, Rates, â€¦) rather than once across all 25 series â€” a pooled PCA finds the single biggest common wobble across every channel and drowns out category-specific variation.

Multivariate regression, HAC standard errors

quant_model_macro_3.py / _4.py

Every ETF's excess return regressed on the factor set, with Neweyâ€“West corrected standard errors since monthly returns are typically autocorrelated.

Normalâ€“normal shrinkage

empirical Bayes

The continuous alternative to a hard significance cutoff: pull each noisy estimate toward a prior mean, weighted by how much precision it actually has.

Likelihood and prior \[ \hat\beta_i \mid \beta_i \sim N(\beta_i,\, se_i^2), \qquad \beta_i \sim N(\mu_0,\, \tau^2) \]

Ridge regression as a MAP estimate

Bayesian linear regression

The multi-regressor generalization of Stage 05 â€” a shared normal prior across the coefficient vector turns out to be exactly the ridge penalty.

Posterior mode of \(\beta \sim N(0,\tau^2 I)\) under a Gaussian likelihood \[ \operatorname{Loss}(\beta) = \|y - X\beta\|^2 + \lambda\|\beta\|^2, \qquad \lambda = \frac{\sigma^2}{\tau^2} \]
